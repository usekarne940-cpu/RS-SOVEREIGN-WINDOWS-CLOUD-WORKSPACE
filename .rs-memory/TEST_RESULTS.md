# TEST_RESULTS

Detailed per-test records (TEST ID / NAME / COMMAND / EXPECTED / ACTUAL / STATUS / EVIDENCE /
ERROR) are stored in `reports/local-validation.json` (machine) and `reports/LOCAL-VALIDATION.md`
(human), generated by `scripts/python/run_all_checks.py` at each validation run. Windows-only
executions are recorded as NOT_RUN locally and scheduled on GitHub runners.
